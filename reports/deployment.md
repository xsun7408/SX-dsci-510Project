# Deploy the explorer to Streamlit Community Cloud

The repository is prepared for deployment. An app is not online merely because
its code has been pushed to GitHub. Creating the hosted app requires the owner's
Streamlit account and GitHub repository access; no API key or secret is needed
by this application.

## Owner steps

1. Sign in at https://share.streamlit.io/ using the GitHub account with access to
   `xsun7408/SX-dsci-510Project`.
2. Choose **Create app** / **New app** and deploy from an existing GitHub repository.
3. Set the repository to `xsun7408/SX-dsci-510Project`, branch to `main`, and main
   file path to `app.py`.
4. In advanced settings, select Python **3.12** when available, matching the
   verified development environment. No secrets need to be entered.
5. Click **Deploy** and wait for dependency installation and startup.
6. Open the actual URL generated by the platform. If the app should be public,
   review its sharing/access setting in the Streamlit dashboard. Repository
   visibility does not need to be changed just to follow this guide.

The generated app URL is the interactive website. A GitHub source-file URL or a
localhost address from the cloud machine is not the hosted website.

## Included data and startup

`app_data/objects.csv` is a compact snapshot of the 3,000 processed API records
with only the display/analysis fields. It excludes raw JSON responses, image
files, logs, and large intermediate tables. `app_data/snapshot.json` records its
rule version and sample size. This snapshot makes a clean deployment independent
of the local raw cache and prevents a 3,000-request download during app startup.

The app prefers the full local processed file if it exists, otherwise uses the
committed compact snapshot. `MET_DATA_PATH` can explicitly select another
processed CSV; it is not needed for standard hosting.

## Verification after deployment

- Default view: **2,990** eligible records.
- European Paintings with the full year range: **1,000** records, median **1760**.
- Changing the year range changes metrics, tables, medium charts, and example rows.
- The medium chart's default n >= 20 rule may hide sparse department-centuries;
  turning it off includes them with a visible caution.
- Example rows are selected from the current filter, not hard-coded.

These expected values describe the committed snapshot. Live API metadata can
change if a new snapshot is generated.

## Refresh the snapshot

From a machine with the completed raw sample:

```bash
python process_data.py data/sample_3000_510.json --output-dir data/processed_3000
python analyze_media.py
python prepare_app_data.py
```

Review the updated aggregates, figure, and compact snapshot before committing.
Raw acquisition remains a separate research step; do not move it into the app's
startup path.
